# Error 404: Her Smile Not Found 💔

A romantic, developer-themed apology web app built with Next.js, Tailwind CSS, and Framer Motion.

## ✨ Features

- **3 interactive stages**: Error Screen → Debug & Apology → Patch Applied
- Glitch + flicker animations on the title
- Animated console typewriter effect
- Animated checklist reveal
- Floating heart particles in the background
- Background music (Web Audio API, toggle button)
- "Still mad? Retry Fix" button to restart
- Fully responsive (mobile + desktop)
- Dark developer aesthetic with neon accents

## 🚀 Getting Started

### 1. Install dependencies

```bash
npm install
```

### 2. Run the development server

```bash
npm run dev
```

### 3. Open in browser

```
http://localhost:3000
```

## 🎨 Customization

Open `app/page.tsx` and change the name at the top:

```ts
const HER_NAME = "Her"; // Change this to her actual name!
```

## 🏗 Build for production

```bash
npm run build
npm start
```
